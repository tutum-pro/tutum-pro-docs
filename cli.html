terminal tutum-admin-cli

info Overview

tutum-admin-cli is an interactive command-line interface for managing certificates in the Tutum Platform. It communicates directly with tutum-engine via gRPC, providing a powerful tool for administrators to perform certificate operations.

check_circle Key Features
  • Interactive certificate management
  • Native gRPC communication (mTLS secured)
  • Batch operations support
  • Multiple output formats (table, JSON, YAML)
  • Shell completion (bash, zsh, fish)
  • Configuration file support
build Technical Details
  • Language: Go 1.21+
  • Framework: Cobra CLI
  • Protocol: gRPC with mTLS
  • Distribution: Docker image, Binary
  • Configuration: YAML, Environment variables

download Installation

Docker (Recommended)

Run tutum-admin-cli as a Docker container:

# Interactive session
docker run -it --rm \
    --network tutum-network \
    tutumpro/tutum-admin-cli:latest

# Single command
docker run --rm \
    --network tutum-network \
    tutumpro/tutum-admin-cli:latest \
    certificate list

Using tutum-cicd (Ansible)

Deploy via Ansible Collection:

ansible-playbook tutum_pro.cicd.cli

See tutum-cicd documentation for details.

Binary Installation

# Download latest release
curl -LO https://github.com/tutum/tutum-admin-cli/releases/latest/download/tutum-cli-linux-amd64

# Make executable
chmod +x tutum-cli-linux-amd64

# Move to PATH
sudo mv tutum-cli-linux-amd64 /usr/local/bin/tutum-cli

settings Configuration

Configuration File

Create ~/.tutum-cli.yaml:

# tutum-admin-cli configuration
engine:
  address: "tutum-engine:9090"    # gRPC endpoint
  tls:
    enabled: true
    cert_file: "/path/to/client.crt"
    key_file: "/path/to/client.key"
    ca_file: "/path/to/ca.crt"

output:
  format: "table"                 # table, json, yaml
  color: true

defaults:
  namespace: "default"
  group: ""

Environment Variables

Variable Description Default
TUTUM_ENGINE_ADDR tutum-engine gRPC address localhost:9090
TUTUM_TLS_ENABLED Enable TLS false
TUTUM_OUTPUT_FORMAT Output format table

code Commands Reference

Certificate Commands

# List all certificates
tutum-cli certificate list

# List with filters
tutum-cli certificate list --namespace production --group web-servers

# Get certificate details
tutum-cli certificate get my-certificate

# Create certificate
tutum-cli certificate create my-certificate \
    --namespace production \
    --group web-servers \
    --cert-file /path/to/cert.pem \
    --key-file /path/to/key.pem

# Update certificate
tutum-cli certificate update my-certificate \
    --cert-file /path/to/new-cert.pem \
    --key-file /path/to/new-key.pem

# Delete certificate
tutum-cli certificate delete my-certificate

# List expiring certificates
tutum-cli certificate expiring --days 30

Namespace Commands

# List namespaces
tutum-cli namespace list

# Create namespace
tutum-cli namespace create production --confidentiality NORMAL

# Create with PARANOIC level (blocks REST API read)
tutum-cli namespace create secrets --confidentiality PARANOIC

Group Commands

# List groups
tutum-cli group list

# Create group
tutum-cli group create web-servers --namespace production

Channel Commands

# List channels
tutum-cli channel list

# Create channel for certificate distribution
tutum-cli channel create frontend-channel \
    --namespace production \
    --groups web-servers,api-servers

Output Formats

# Table format (default)
tutum-cli certificate list

# JSON format
tutum-cli certificate list -o json

# YAML format
tutum-cli certificate list -o yaml

# Wide table (more columns)
tutum-cli certificate list -o wide

tutum-admin-cli communicates with tutum-engine via gRPC:

keyboard Shell Completion

Bash

# Generate completion script
tutum-cli completion bash > /etc/bash_completion.d/tutum-cli

# Or add to .bashrc
echo 'source <(tutum-cli completion bash)' >> ~/.bashrc

Zsh

# Add to .zshrc
echo 'source <(tutum-cli completion zsh)' >> ~/.zshrc

Fish

tutum-cli completion fish > ~/.config/fish/completions/tutum-cli.fish

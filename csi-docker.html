storage Docker CSI Driver (tutum-csi-driver-docker)

Docker Volume Plugin for Certificate Management - Standalone Docker Environment Support

info Overview

tutum-csi-driver-docker is a Docker volume plugin that enables containers to mount X.509 certificates as volumes. It follows the Docker Volume Plugin API specification and integrates seamlessly with Docker Engine.

lightbulb
Use Case: Ideal for standalone Docker deployments, Docker Compose environments, and Docker Swarm clusters where Kubernetes is not available.

download Installation

Option 1: Systemd Service (Recommended)

# Copy binary
sudo cp tutum-csi-driver-docker /usr/local/bin/
sudo chmod +x /usr/local/bin/tutum-csi-driver-docker

# Create plugin directory
sudo mkdir -p /run/docker/plugins

# Install systemd service
sudo cp tutum-csi-driver-docker.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable tutum-csi-driver-docker
sudo systemctl start tutum-csi-driver-docker

# Verify
sudo systemctl status tutum-csi-driver-docker

Option 2: Docker Managed Plugin

# Install from Docker Hub
docker plugin install tutumpro/tutum-csi-driver-docker \
  TUTUM_ENGINE_ENDPOINT=tutum-engine:9090

# Enable plugin
docker plugin enable tutumpro/tutum-csi-driver-docker

# Verify
docker plugin ls

Systemd Service File

[Unit]
Description=Tutum Docker Volume Plugin
After=docker.service
Requires=docker.service

[Service]
Type=simple
ExecStart=/usr/local/bin/tutum-csi-driver-docker
Environment=TUTUM_ENGINE_ENDPOINT=tutum-engine:9090
Environment=TUTUM_SOCKET_PATH=/run/docker/plugins/tutum.sock
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target

play_arrow Usage

Docker CLI

# Create volume
docker volume create \
  --driver tutum \
  --opt certificate-name=my-app-cert \
  --opt group-id=production-group-uuid \
  --opt namespace=production \
  my-cert-volume

# Use in container
docker run -d \
  --name my-app \
  -v my-cert-volume:/etc/ssl/certs/my-app:ro \
  my-app:latest

# Inspect volume
docker volume inspect my-cert-volume

# Remove volume
docker volume rm my-cert-volume

Docker Compose

version: '3.8'

services:
  my-app:
    image: my-app:latest
    volumes:
      - type: volume
        source: my-cert
        target: /etc/ssl/certs/my-app
        read_only: true

volumes:
  my-cert:
    driver: tutum
    driver_opts:
      certificate-name: my-app-cert
      group-id: production-group-uuid
      namespace: production
      channel: internal
      auth-token: ${TUTUM_AUTH_TOKEN}

Docker Swarm

version: '3.8'

services:
  my-app:
    image: my-app:latest
    deploy:
      replicas: 3
    volumes:
      - type: volume
        source: my-cert
        target: /etc/ssl/certs/my-app
        read_only: true
        volume:
          nocopy: true

volumes:
  my-cert:
    driver: tutum
    driver_opts:
      certificate-name: my-app-cert
      group-id: production-group-uuid
      namespace: production

Mounted Files

/etc/ssl/certs/my-app/
├── tls.crt          # Certificate (PEM)
├── tls.key          # Private key (PEM)
├── ca.crt           # CA chain (PEM)
└── metadata.json    # Certificate metadata

search Plugin Discovery

Docker discovers volume plugins through spec files or Unix sockets:

Socket-based Discovery

# Plugin listens on Unix socket
/run/docker/plugins/tutum.sock

# Docker automatically discovers plugins in this directory

Spec File Discovery

# Create spec file
echo "unix:///run/docker/plugins/tutum.sock" | \
  sudo tee /etc/docker/plugins/tutum.spec

# Docker reads spec files from /etc/docker/plugins/

JSON Spec File (Advanced)

# /etc/docker/plugins/tutum.json
{
  "Name": "tutum",
  "Addr": "unix:///run/docker/plugins/tutum.sock",
  "TLSConfig": {
    "InsecureSkipVerify": false,
    "CAFile": "/etc/tutum/ca.crt",
    "CertFile": "/etc/tutum/client.crt",
    "KeyFile": "/etc/tutum/client.key"
  }
}

bug_report Troubleshooting

Check Plugin Status

# Systemd service logs
sudo journalctl -u tutum-csi-driver-docker -f

# Check socket exists
ls -la /run/docker/plugins/tutum.sock

# Test socket connectivity
curl --unix-socket /run/docker/plugins/tutum.sock http://localhost/VolumeDriver.List

# Docker plugin logs (if using managed plugin)
docker plugin inspect tutumpro/tutum-csi-driver-docker

Common Issues

Ensure the plugin is running and the socket exists:

sudo systemctl status tutum-csi-driver-docker
ls -la /run/docker/plugins/tutum.sock

Check network connectivity to tutum-engine:

nc -zv tutum-engine 9090
curl http://tutum-engine:8080/health

Check volume directory permissions:

ls -la /var/lib/tutum/
sudo chown -R root:root /var/lib/tutum/

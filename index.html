info Platform Overview

Tutum is a comprehensive X.509 certificate management platform designed for containerized environments (Kubernetes and Docker Engine). Built entirely in Go with full multi-architecture support (amd64/arm64), it provides secure certificate distribution, envelope encryption, and seamless integration with container orchestration systems.

lightbulb
Design Philosophy: Tutum follows a microservices architecture with clear separation between certificate storage, retrieval, and consumption layers, ensuring security, scalability, and maintainability.

Solution Structure

The platform consists of interconnected components working together to provide end-to-end certificate management. Administrators interact via REST API or CLI. For certificate distribution, Kubernetes supports two modes: CSI Driver (volume-based) and Operator (CRD-based). Docker uses CSI Driver only.

info
Kubernetes Injection Modes:
  • CSI Driver Mode: Mounts certificates as ephemeral volumes (requires privileged containers)
  • Operator Mode: Syncs certificates to Kubernetes Secrets via TutumCertificate CRD (rootless, recommended)

🎯 Operator Mode (Recommended)
  • Rootless: No privileged containers
  • Native: Uses Kubernetes Secrets
  • Declarative: TutumCertificate CRD
  • Auto-sync: Kubelet updates volumes automatically
  • OpenShift: Compatible with restricted SCCs
⚠️ CSI Driver Mode (Legacy)
  • Privileged: Requires escalated permissions
  • Direct mount: CSI ephemeral volumes
  • Pod restart: Required for cert updates
  • DaemonSet: Runs on every node
  • Use case: Legacy deployments

All projects use GNU Make for build automation with standardized targets:

  • make build - Build binary
  • make test - Run unit tests
  • make lint - Run linters (golangci-lint)
  • make docker-build - Build Docker image
  • make clean - Remove build artifacts

Cross-Compilation

Multi-architecture support through Go's cross-compilation:

GOOS=linux GOARCH=amd64 go build -o bin/app-amd64 ./cmd/app
GOOS=linux GOARCH=arm64 go build -o bin/app-arm64 ./cmd/app

rocket_launch Getting Started

Quick Start - Full Platform

# Clone repository
git clone https://github.com/tutum/platform
cd platform

# Start tutum-engine with PostgreSQL
cd tutum-engine
export TUTUM_MASTER_KEY=$(openssl rand -base64 32)
make db-up
make db-migrate
make run

# In another terminal - Deploy Kubernetes Operator (Recommended)
cd tutum-operator-k8s
kubectl apply -f deploy/crd.yaml
kubectl apply -f deploy/operator.yaml

# Or deploy CSI Driver (Legacy)
cd tutum-csi-driver-k8s
make docker-build
kubectl apply -f deploy/

# Or deploy Docker plugin
cd tutum-csi-driver-docker
make build
sudo systemctl start tutum-csi-driver
